# A8 Chargers

Web page to monitor and control ISDT A8 Air battery chargers over Bluetooth, straight from the browser.

Open https://productionaudiodev.github.io/a8-chargers/ in:
- Chrome or Edge (Mac, Windows, Android), or
- Safari on iPhone with the free [beacio](https://beacio.com/) extension turned on, or the Bluefy browser.

Add `#demo` to the address to see recorded data without chargers.
Not affiliated with ISDT. Wrong charge settings can damage cells or start a fire.
